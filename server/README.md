# Server

ASP.NET Core REST API for the Enterprise Full-Stack Reference application.

## Current Feature

Project Search demonstrates controllers, typed DTOs, an application service, Entity Framework Core, LINQ query composition, filtering, sorting, pagination, cancellation tokens, and SQL Server persistence.

## Run

```bash
cd EnterpriseFullStackReference.Api
dotnet restore
dotnet run --launch-profile https
```

Development endpoints:

```text
https://localhost:7001
http://localhost:5081
```

See `docs/LOCAL-DEVELOPMENT.md` for database and client setup.
